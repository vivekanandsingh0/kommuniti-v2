Tile Colour Assignment Logic

Month rotates through 8 brand-adjacent colours (Cyan, Dark Red, Blue-Purple, Orange, Green, Olive, Charcoal, Steel) — never repeating consecutively
Date numeral is large (56px Syne 800) set at 15% opacity as background texture element
Event icon sits bottom-right at 20% opacity — decorative, never interfering with text readability
All tiles: 1:1 aspect ratio on mobile, 3:4 on desktop grid
Hover: slight scale(1.02) + box-shadow glow in tile's dominant colour

Splash Screen & Entry Experience

Splash Animation Sequence
🌻

A Feeling of Home

Animation Timeline (4.5 seconds total)

0–0.8s: Pure black screen. Single golden pixel appears at centre. Gentle spin begins.
0.8–1.8s: Pixel zooms out — revealing it was always part of a larger mosaic. 16×16 pixel grid expands to fill screen. Pixels pulse gold-to-dark in wave pattern.
1.8–2.8s: Matrix re-arrangement — pixels slide and settle to form the sunflower icon (stylised, 64×64 pixel grid). Warm hum sound.
2.8–3.4s: "Kommuniti" wordmark appears letter by letter in Syne 800. First K in gold, rest in ivory.
3.4–4.0s: "A Feeling of Home" fades in beneath in Cormorant Garamond italic. Soft glow on sunflower.
4.0–4.5s: Enter button pulses gently (border glow animation). Auto-proceeds to main site after 3s idle.

Technical Implementation

CSS Grid pixel animation — no canvas, no WebGL. Pure CSS keyframes.
Sunflower pixelation: SVG with clip-path masked by pixel grid overlay
Auto-skip: if user had previously visited, reduce to 1.5s version
Accessibility: prefers-reduced-motion → skip to Enter screen immediately
Mobile: same animation but at 60% scale. Touch "Enter" to proceed.

Entry Gate Copy

"A Feeling of Home"
Sub-tagline option (appears 1s after main tagline): "Where community is the currency."
Micro-copy below Enter: Join 2,000+ Kore members across Kerala

KO Reads — Democratic Writing Platform
Thread Creation · Contribution · Review · KO Coins Earned
KO Reads Concept

KO Reads is a democratised book-writing and research platform. An Author creates a thread (topic/chapter). Community members submit contributions (paragraphs, references, insights). The Author reviews each contribution — accepting or rejecting based on validity and citations. Accepted contributions earn KO Coins for the contributor. The result is a collaboratively authored work with full attribution.

KO Reads — How Contributions Work (User Flow)

Author creates Thread: Title, topic brief, chapter structure, reward per accepted contribution (₹ equivalent in KO Coins), submission deadline, citation requirements
Member contributes: Write a paragraph (200–500 words) with minimum 1 verifiable reference. Preview before submit. Word count counter visible.
Author reviews: Accept (coins awarded immediately) / Reject with reason (member can edit and resubmit) / Request citation improvement
Attribution: Every accepted contributor is credited in the final published work with their Kore name and contribution count
Publication: When thread is marked complete by Author, the full text is published on KO Reads as a Community Document. Available for ₹ or KO Coins to read in full.
AI moderation assist: Anya scans submissions for plagiarism and flags missing citations before they reach the Author, saving review time

Technical Specifications for Developers
Stack · Performance · SEO · Analytics · Integrations

Recommended Tech Stack

Framework: Next.js 15 (App Router) — for SSR/SSG SEO benefits and API routes
Styling: Tailwind CSS + CSS Variables for design tokens. No UI library — custom components only.
Animation: Framer Motion for page transitions and scroll reveals. CSS keyframes for pixel animations.
Fonts: Google Fonts — Syne, Cormorant Garamond, Space Mono, Rajdhani. Load only needed weights.
Maps: MapLibre GL JS with Stadia Maps API. Pixel shader layer for game map aesthetic.
Payments: Razorpay SDK (Web). KO Coin deductions via internal API (connects to Supabase ko_transactions).
Backend API: Next.js API routes → connects to existing Fastify server (from app build doc)
CMS: Sanity.io for Kreate/KO Reads content + Kommute listing descriptions
Analytics: PostHog (privacy-first). Track: page views, booking funnel drop-off, KO Reads engagement

Performance Targets

Largest Contentful Paint: under 2.5s (target: 1.8s)
Cumulative Layout Shift: under 0.1
First Input Delay: under 100ms
Lighthouse Score: 90+ Performance, 95+ Accessibility, 100 SEO
Image format: WebP with AVIF fallback. Lazy load all below-fold images.
Splash animation: CSS-only, no JavaScript dependency. Loads in under 200ms.

SEO Strategy

Homepage meta: "Kommuniti — A Feeling of Home | Community Commerce Kerala | Kore Membership"
Kommute pages: "KO Pod Stays Kerala | Community Homestays Wayanad | Kore Experiences [City]"
Konnect pages: "[Workshop Topic] Kerala 2026 | Community Workshop [City] | Konnect Session"
KO Reads: "[Thread Title] by [Author] | Kommuniti KO Reads | Democratic Research Kerala"
Structured data: Event schema for Konnect. Product schema for KO Store. Organization schema for Kores.
Sitemap: Auto-generated XML sitemap. Update on new Kore/event/listing publish.

Key Integrations

App Download: Universal link that detects device and redirects to App Store / Play Store / APK
Razorpay: Standard checkout for ₹ payments. Payout API for KO Coin → UPI conversion
WhatsApp: Share buttons on all listings. Auto-generated share text with property/event link
DigiPin API: dac.indiapost.gov.in — convert listing GPS coordinates to DigiPin for display
Supabase: Real-time KO Coin balance, KSS scores, Kore member data via existing API
Anya AI: Web widget version of Anya chat (simplified). Available on Kommute, Konnect, Profile.

App Download CTA — Priority

The website's primary conversion goal is app downloads. The "Get the App" button should be in the navigation on every page.
Bottom of every major page section: "The full KoKo game is in the app. Download now to start earning."
App download page: QR code (generated dynamically with UTM tracking) + Store badges + 3 feature highlights
For logged-in web users: "Complete your profile in the app for 200 bonus KO Coins" — drives cross-platform conversion
