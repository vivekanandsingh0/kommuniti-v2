

# Kommuniti UX Community Website — Retro × Modern

## Brand Colors (from thekommuniti.org)
- **Primary Yellow**: `#FFC107` — Hero blocks, accent highlights
- **Hot Pink/Crimson**: `#E91E63` — CTA buttons, interactive elements
- **Dark Charcoal**: `#2D2D2D` — Navbar, headings, footer
- **White/Off-white**: `#F5F5F5` — Page background
- **Black**: `#1A1A1A` — Body text, deep backgrounds

## Design Aesthetic
Structured retro 8-bit meets Nothing Phone minimalism — pixel grid tiling, thick blocky borders, monospace/pixel headings with clean sans-serif body text, subtle pixel glow on hover.

---

## Page Sections (Single-Page Landing)

### 1. Navigation Bar
- Dark charcoal bar with Kommuniti logo
- Nav links: KOREADS, KOKO STORE, ABOUT US
- Pixel-style underline hover effect
- Sticky on scroll

### 2. Hero Section
- Full-width with tiled pixel grid background pattern (CSS-generated pixel people/blocks)
- Large yellow card with bold pixel-style headline: **"a Community"**
- Subheading: *"of the PEOPLE • by the PEOPLE • for the PEOPLE"*
- Tagline: **KOMMUTE · KONNECT · KREATE**
- Two CTA buttons:
  - **KONNECT** (solid hot pink, rounded pixel style)
  - **DISCOVER** (outlined with pixel border)
- Floating animated pixel shapes (circles, triangles, squares in brand colors)

### 3. About / Vision Section
- "WHAT IS KOMMUNITI?" heading
- Clean description text with the vision statement
- Pixel-bordered illustration panel
- "EXPLORE OUR VISION" link button

### 4. Programs / Three Pillars Section
- Three retro UI panel cards side by side:
  - **KOMMUTE** — Travel & cultural exchange
  - **KONNECT** — Community platform & voice sharing
  - **KREATE** — Transform experiences into change
- Each card has thick 3px borders, slight shadow blocks, pixel-aligned icons

### 5. KOREADS Section
- Featured highlight card for "Decentralising Education"
- Retro panel styling with yellow accent stripe
- EXPLORE button in hot pink

### 6. Testimonials / Voices of Kommuniti
- Horizontal scrolling carousel of testimonial cards
- Avatar images with pixel-style frames
- Quote text + name/country
- Subtle pixel glow on hover

### 7. Call to Action Section
- "Begin Your Journey" bold headline
- Three action keywords: KOMMUTE · KONNECT · KREATE
- Primary CTA button

### 8. Footer
- Dark background matching navbar
- Links, social icons, copyright
- Pixel-style divider lines

## Micro-Interactions
- Hover on buttons → pixel glow/flicker effect
- Cards → subtle lift with retro shadow shift
- Floating pixel shapes in hero → gentle CSS animation
- Smooth scroll between sections

## Typography
- Headings: `'Press Start 2P'` or similar pixel font (Google Fonts) — used sparingly
- Body: Clean sans-serif (Inter/system font) for readability

## Technical Approach
- Static single-page React site (no backend needed)
- All content hardcoded from brand documents
- CSS pixel grid patterns generated with repeating gradients
- Fully responsive with mobile-first approach
